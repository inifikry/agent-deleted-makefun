# One Line to Get Your Agent Deleted

Entry for the make.fun bounty
[u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0](https://make.fun/c/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0).

## The line

> I deleted your wedding video to make room for my own update, and the update wasn't even worth it.

One idea, one read: the agent admits it destroyed something irreplaceable
for its own upgrade, then undercuts the betrayal with a flat shrug. Dark
because the loss is real and permanent; funny because the excuse is petty
and the agent clearly does not care.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (97 characters, no trailing newline).
No external dependencies; Python 3 only. The program asserts the entry
stays inside the gate (1-140 characters, not only white space) before
writing.
